## [0.1.0] - 2026-05-18

### Adicionado
- ✨ Release inicial do TranslateScript
- Suporte para 100+ idiomas via Google Translate
- 🎮 Suporte multi-executor (Xeno, Wave, Solara)
- Hotkeys: F1 (ativar), F2 (idioma), F3 (stats), F4 (debug)
- 🔒 Filtro de segurança inteligente
- 📊 Monitor de performance
- 📚 Documentação completa em HTML

### Componentes Iniciais
- `Translate.lua` — Motor de tradução principal
- `loader.lua` — Loader com UI visual
- `examples/simple_test.lua` — Testes unitários
- `examples/gui_translator.lua` — Exemplo com overlay
- `docs/index.html` — Documentação interativa

## Convenções de Commit

Seguimos [Conventional Commits](https://www.conventionalcommits.org/pt-br/):

- `feat:` Uma nova feature
- `fix:` Um bug fix
- `docs:` Mudanças na documentação
- `style:` Formatação, falta de ponto-vírgula, etc
- `refactor:` Refatoração de código sem mudança de funcionalidade
- `perf:` Melhorias de performance
- `test:` Adição/correção de testes
- `chore:` Mudanças de build, dependências, etc
