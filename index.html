TranslateScript

Biblioteca Luau de tradução automática para executores Roblox. Traduz em tempo real todos os textos visíveis de qualquer jogo.

Luau Executor Xeno · Wave · Solara Google Translate API MIT License

Visão Geral

TranslateScript é uma biblioteca de tradução universal desenvolvida para funcionar dentro do ambiente de executores Roblox (Xeno, Wave, Solara, Synapse X, KRNL, etc.). O objetivo é simples: traduzir automaticamente todos os TextLabels, TextButtons e TextBoxes de qualquer jogo em tempo real, para o idioma que o jogador escolher.

A biblioteca é dividida em dois arquivos principais: Translate.lua, que é o módulo puro de tradução (baixado do GitHub via loadstring), e loader.lua, que o usuário cola no executor para inicializar tudo automaticamente.

✓
Nenhuma vantagem em jogo. O script apenas lê e sobrescreve texto visível — sem modificar lógica de jogo, stats ou comportamento de personagens.

Quick Start

Opção 1 — loader.lua (recomendado)

Cole o conteúdo de loader.lua no seu executor e execute. Ele faz tudo automaticamente.

Opção 2 — loadstring manual

Se quiser usar a biblioteca em outro script, carregue assim:

lua manual_load.lua 
local TranslatorLib = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/NixScripts/Translator/refs/heads/main/Translate.lua"
))()

local t = TranslatorLib.new()

-- Tradução simples
print(t:translate("Hello World", "pt"))
-- Output: "Olá Mundo"

-- Idioma de origem explícito
print(t:translate("Bonjour", "pt", "fr"))
-- Output: "Bom dia"
⚠
A URL deve ser sempre o link raw do GitHub (raw.githubusercontent.com), nunca a URL da página do repositório (github.com). A página HTML não é código Lua válido.

Pipeline de Tradução

Cada vez que translateVerbose(text, targetLang) é chamado, o texto passa por estas etapas em ordem. Cada etapa retorna um reason que o loader usa para contabilizar stats precisos:

1
Sanitização
Remove tags RichText (<font color>, <b>), entidades HTML (&nbsp;, &quot;) e faz trim de espaços
sempre
2
skipReason()
Retorna o motivo exato: skip_short (<2 chars), skip_num (só números/símbolos), skip_noltr (sem letras), skip_word (na lista SKIP_WORDS)
→ reason
3
Lookup no cache
Chave = textoLimpo|targetLang. Se existir retorna instantaneamente sem nenhuma requisição HTTP
→ cache hit
4
Google Translate API
GET para translate.googleapis.com com client=gtx. Parse do JSON, decode de \uXXXX. Retorna result, "api" em caso de sucesso.
→ "api"
5
MyMemory (fallback)
Se o Google falhar, GET para api.mymemory.translated.net. Retorna result, "api_fb". Se ambas falharem retorna text, "api_failed".
→ "api_fb"
6
Salva no cache + retorna
Armazena via _storeCache() (máx. 1000 entradas, auto-limpa). Se API retornou o mesmo texto, reason = "same". Se falhou tudo, reason = "api_failed" e entra no ErrorLog.
→ "cache"

Ambiente Executor

Executores Roblox modificam o ambiente Luau padrão, desbloqueando funções que o Roblox bloqueia por padrão. Estas são as funções que a biblioteca usa:

Função Tipo Descrição
game:HttpGet(url) GET Baixa conteúdo de URLs externas. Principal método HTTP do projeto. Desbloqueado pelo executor.
loadstring(code) compile Compila string como código Lua e retorna uma função executável. Bloqueado no Roblox padrão, liberado pelo executor.
getgenv() env Retorna o ambiente global do executor (padrão UNC). Usado para compartilhar estado entre scripts. Possui fallback para _G caso não exista.
task.spawn / task.delay async API de concorrência do Roblox. Usada para não bloquear a thread principal durante scans e traduções.
ℹ
Todas as chamadas HTTP são GET puro. Nenhuma requisição POST é feita. Isso garante compatibilidade máxima com qualquer executor, já que POST depende de funções UNC adicionais (request, http_request).

Translate.lua — Referência da API

Módulo puro de tradução. Pode ser usado de forma independente em qualquer script de executor.

Translator.new () → Translator → Translator instance

Cria e retorna uma nova instância do tradutor com cache próprio e configurações padrão.

local t = TranslatorLib.new()
translator:translateVerbose (text: string, targetLang: string, sourceLang?: string) → string, string → result, reason

Versão estendida do translate(). Retorna dois valores: o texto traduzido e o motivo exato do resultado. Use este método no lugar de translate() quando precisar de stats precisos ou debug de skip.

ReasonSignificado
"api"Traduzido via Google Translate
"api_fb"Traduzido via MyMemory (fallback)
"cache"Servido do cache, sem HTTP
"custom"Traduzido via função customizada
"skip_short"Texto com menos de 2 caracteres
"skip_num"Apenas números ou símbolos
"skip_word"Palavra na lista SKIP_WORDS
"skip_noltr"Sem letras no texto
"same"API retornou o mesmo texto (já no idioma alvo)
"api_failed"Todas as APIs falharam
 
local result, reason = t:translateVerbose("Hello World", "pt")
-- "Olá Mundo"   "api"

local result, reason = t:translateVerbose("Shift", "pt")
-- "Shift"        "skip_word"

local result, reason = t:translateVerbose("Hello", "pt")
-- "Hello"        "cache"  ← segunda chamada, vem do cache
translator:translate (text: string, targetLang: string, sourceLang?: string) → string → string

Método de compatibilidade — chama translateVerbose() internamente e retorna apenas o resultado. Use translateVerbose() quando precisar do motivo para debug ou stats.

ParâmetroTipoPadrão
textstring—
targetLangstring"pt"
sourceLangstring?"auto"
 
t:translate("Press E to interact", "pt")
-- "Pressione E para interagir"

t:translate("Bienvenue", "pt", "fr")
-- "Bem-vindo"

t:translate("Shift", "pt")
-- "Shift"  ← SKIP_WORDS, retorna original
translator:clearCache () → void

Limpa todo o cache interno. Útil quando o idioma alvo é trocado em runtime ou quando se quer forçar novas requisições à API.

t:clearCache()
print(t:getCacheSize()) -- 0
translator:getCacheSize () → number → number

Retorna o número de entradas atualmente armazenadas no cache. Útil para debug e para monitorar o uso de memória. O cache é limpo automaticamente ao atingir 1000 entradas.

translator:setRequestFunction (fn: function) → void

Define uma função customizada para fazer as requisições HTTP, substituindo o comportamento padrão (Google → MyMemory). Útil para usar sua própria API de tradução ou proxy.

t:setRequestFunction(function(text, targetLang, sourceLang)
    -- Sua lógica customizada aqui
    local result = minhAPI:traduzir(text, targetLang)
    return result
end)

loader.lua — Comportamento

O loader é o script que o usuário cola e executa no executor. Ele orquestra tudo automaticamente.

Proteção de dupla execução

Ao executar, o loader verifica genv.__TRANSLATESCRIPT_LOADED. Se já estiver true, avisa e encerra imediatamente sem duplicar conexões ou instâncias.

Carregamento da biblioteca

-- Padrão correto de carregamento em executores:
local ok, raw = pcall(function()
    return game:HttpGet(url)
end)

local chunk, compileErr = loadstring(raw)
if chunk then
    local ok2, result = pcall(chunk)
    -- result = TranslatorLib
end

O loadstring e a execução do chunk são separados para capturar erros distintos: erro de compilação (código inválido) vs erro de execução (runtime error na lib).

Debounce de typewriter

Jogos como Deepwoken exibem texto caractere por caractere (typewriter effect). O loader aguarda 0.8 segundos sem novas mudanças no .Text antes de enviar para tradução, evitando múltiplas requisições para textos incompletos.

Loop prevention

Quando o loader escreve a tradução em obj.Text, isso dispara novamente o evento GetPropertyChangedSignal("Text"). O processingSet marca o objeto como "em processamento" e ignora esses eventos secundários.

Variáveis expostas via getgenv()

-- Acessíveis em outros scripts após o loader executar:
genv.TranslatorLib  -- A classe Translator (para criar novas instâncias)
genv.translator     -- A instância ativa usada pelo loader

Atalhos de Teclado

Disponíveis enquanto o loader está rodando no jogo:

F1 Liga / Desliga a tradução. Ao religar, faz um rescan completo da GUI automaticamente.
F2 Limpa o cache e re-traduz tudo do zero. Útil após carregar uma nova área do jogo.
F3 Estatísticas detalhadas: breakdown real de skip intencional / mesmo texto / falha de API / traduzidos / cache hits / uptime.
F4 Log de erros — últimos 20 erros com horário, categoria (RUNTIME ERROR, API FAILED, SCAN ERROR, WATCH ERROR) e contexto do texto.

Configuração

Todas as variáveis de configuração ficam no topo do loader.lua, identificadas por comentários:

lua loader.lua — variáveis de configuração 
local TARGET_LANG = "pt"    -- idioma alvo (código IETF)
local SOURCE_LANG = "auto"  -- detecção automática de origem

local DEBOUNCE_TIME = 0.8  -- segundos aguardando typewriter terminar
local RATE_DELAY    = 0.2  -- intervalo mínimo entre requisições (segundos)
VariávelPadrãoDescrição
TARGET_LANG"pt"Idioma para o qual traduzir. Aceita qualquer código Google Translate.
SOURCE_LANG"auto"Idioma de origem. "auto" deixa o Google detectar automaticamente.
DEBOUNCE_TIME0.8Tempo de espera após a última mudança no texto antes de enviar para tradução. Aumentar se o jogo tiver textos longos com typewriter lento.
RATE_DELAY0.2Intervalo mínimo entre requisições à API. Diminuir aumenta a velocidade, mas pode gerar bloqueio de IP.
DEBUG_SKIPfalseQuando true, loga no console cada texto pulado com o motivo exato (skip_word, skip_num, etc.). Útil para calibrar a lista SKIP_WORDS.

Troubleshooting

❌ "Falha ao baixar" / "attempt to call a nil value"

O executor não conseguiu acessar a URL. Verifique:

  • O arquivo no GitHub se chama exatamente Translate.lua (com .lua)
  • Está usando a URL raw: raw.githubusercontent.com
  • O executor tem permissão de HTTP (verifique as configurações do executor)

⚠ "Erro de compilação"

O código baixado não é Lua válido. Geralmente significa que a URL retornou HTML (página 404 do GitHub). Confirme a URL abrindo no navegador — deve mostrar código Lua puro, não uma página HTML.

⚠ Textos não são traduzidos

Verifique se o texto não está na lista SKIP_WORDS, se tem menos de 2 caracteres, ou se é composto apenas por números e símbolos. Ative DEBUG_SKIP = true no loader para ver no console cada texto pulado com o motivo exato. Use F3 para ver o breakdown completo de skip.

⚠ Tradução atrasada ou incompleta

O debounce de 0.8s pode ser curto para jogos com typewriter muito lento. Aumente DEBOUNCE_TIME para 1.5 ou 2.0 no loader.

⚠ "Já está rodando"

A proteção de dupla execução detectou uma instância anterior. Pressione F2 para resetar tudo e re-iniciar, ou feche e abra o jogo novamente.
