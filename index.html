TranslateScript

Biblioteca Luau de tradução automática para executores Roblox. Traduz em tempo real todos os textos visíveis de qualquer jogo.

Luau Executor Xeno · Wave · Solara Google Translate API GET puro — sem POST

Visão Geral

TranslateScript é uma biblioteca modular de tradução desenvolvida para rodar dentro do ambiente de executores Roblox. O objetivo é traduzir automaticamente todos os TextLabels, TextButtons e TextBoxes de qualquer jogo em tempo real, sem intervenção manual e sem modificar lógica de jogo.

A arquitetura é dividida em dois arquivos: Translate.lua é o módulo puro (hospedado no GitHub, carregado via loadstring), e loader.lua é o script que o usuário cola no executor para inicializar e orquestrar tudo.

✓
Nenhuma vantagem em jogo. O script apenas lê e sobrescreve texto visível — sem modificar stats, lógica ou comportamento de personagens.

Quick Start

Loader (recomendado)

Cole o conteúdo de loader.lua no executor e execute. Ele baixa e ativa tudo automaticamente.

loadstring manual

lua
local t = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/NixScripts/Translator/refs/heads/main/Translate.lua"
))().new()

-- retorna só o texto traduzido
print(t:translate("Hello World", "pt"))
-- "Olá Mundo"

-- retorna texto + motivo (para debug e stats)
local result, reason = t:translateVerbose("Hello World", "pt")
print(result, reason)  -- "Olá Mundo"   "api"
⚠
A URL deve ser sempre o link raw do GitHub (raw.githubusercontent.com), não a URL da página do repositório. A página HTML não é código Lua válido e o loadstring vai falhar silenciosamente.

Pipeline de Tradução

Cada chamada a translateVerbose(text, targetLang) percorre estas etapas. O reason retornado identifica exatamente onde o texto foi resolvido:

1
sanitize()
Remove tags RichText (<font>, <b>), entidades HTML (&nbsp;, &quot;), faz trim
sempre
2
skipReason()
Retorna o motivo se o texto não precisa de tradução: skip_short, skip_num, skip_noltr, skip_word
→ reason
3
Cache lookup
Chave = textoLimpo|targetLang. Se existir, retorna sem nenhuma requisição HTTP
→ "cache"
4
Google Translate
GET para translate.googleapis.com com client=gtx. Parse do JSON aninhado, decode de \uXXXX
→ "api"
5
MyMemory (fallback)
Se o Google falhar, GET para api.mymemory.translated.net. Parse do campo translatedText
→ "api_fb"
6
_storeCache() + retorna
Salva no cache (máx. 1000, auto-limpa). Se API retornou igual: "same". Se tudo falhou: "api_failed"
→ result

Ambiente Executor

Executores modificam o ambiente Luau padrão, desbloqueando funções que o Roblox normalmente bloqueia. Estas são as únicas funções que a biblioteca usa:

FunçãoDescrição
game:HttpGet(url)Baixa conteúdo de URLs externas. Único método HTTP do projeto — GET puro, sem POST necessário.
loadstring(code)Compila string como código Lua executável. Bloqueado no Roblox padrão, liberado pelo executor.
getgenv()Ambiente global do executor (padrão UNC). Usado para proteção de dupla execução. Tem fallback para _G.
task.spawn / task.delayConcorrência assíncrona. Evita bloquear a thread principal durante scans e traduções.
ℹ
Todas as requisições HTTP são GET puro. Isso garante compatibilidade máxima — POST depende de request() ou http_request(), que nem todos os executores têm.

Filtro de Segurança — isSafeToTranslate

Quando modificamos obj.Text, outros scripts do jogo que estejam ouvindo o mesmo label via GetPropertyChangedSignal também disparam. Se o jogo usa aquele label como dado (um stat, nome de mutation, valor numérico), nossa tradução quebra a lógica dele.

O filtro isSafeToTranslate(obj) bloqueia labels perigosos antes de qualquer processamento:

lualoader.lua
local UNSAFE_SEGMENTS = {
    ["value"]=true, ["data"]=true,  ["score"]=true,
    ["count"]=true, ["stat"]=true,   ["stats"]=true,
    ["timer"]=true, ["clock"]=true,  ["ping"]=true,
    ["userid"]=true, ["playerid"]=true,
    ["mutation"]=true, ["mutations"]=true,
}

local function isSafeToTranslate(obj)
    local name = obj.Name:lower()
    -- gmatch por segmento — evita falso positivo por substring
    -- "DialogueLabel" → "dialogue","label" → seguro ✓
    -- "MutationValue" → "mutation","value" → bloqueado ✗
    for segment in name:gmatch("[a-z]+") do
        if UNSAFE_SEGMENTS[segment] then return false end
    end
    -- texto puramente numérico nunca traduzir
    if obj.Text:match("^%s*[%d%+%-%.,%%/:]+%s*$") then return false end
    return true
end
⚠
Se um jogo específico ainda causar erro após o filtro, pressione F4 para ver o log de erros e identifique o nome exato do label. Adicione o segmento problemático em UNSAFE_SEGMENTS.

Translate.lua — Referência da API

Translator.new() → Translator→ instance

Cria nova instância com cache próprio e configurações padrão.

translator:translateVerbose(text, targetLang, sourceLang?) → string, string→ result, reason

Método principal. Retorna o texto traduzido e o motivo exato. Use este no loader para stats precisos.

ReasonSignificado
"api"Traduzido via Google Translate
"api_fb"Traduzido via MyMemory (fallback)
"cache"Servido do cache, sem HTTP
"custom"Traduzido via função customizada
"skip_short"Menos de 2 caracteres
"skip_num"Apenas números ou símbolos
"skip_word"Na lista SKIP_WORDS
"skip_noltr"Sem letras no texto
"same"API retornou o mesmo texto
"api_failed"Todas as APIs falharam
translator:translate(text, targetLang, sourceLang?) → string→ string

Wrapper de compatibilidade sobre translateVerbose. Retorna apenas o texto, descarta o reason. Use quando não precisar dos stats.

translator:clearCache() → void

Limpa o cache interno. Útil ao trocar idioma alvo em runtime.

translator:getCacheSize() → number→ number

Retorna o número de entradas no cache. Auto-limpa ao atingir 1000 entradas.

translator:setRequestFunction(fn: function) → void

Substitui toda a lógica HTTP por uma função customizada. Útil para usar proxy ou API própria.

t:setRequestFunction(function(text, targetLang, sourceLang)
    return minhaAPI:traduzir(text, targetLang)
end)

loader.lua — Comportamento

Proteção de dupla execução

Ao executar, o loader verifica genv.__TRANSLATESCRIPT_LOADED. Se true, avisa e encerra sem duplicar conexões.

Debounce de typewriter

Aguarda 0.8s sem mudanças no .Text antes de enviar para tradução. Evita múltiplas requisições para textos sendo exibidos caractere por caractere.

Loop prevention

processingSet[obj] = true marca o objeto durante o processamento. Quando o loader escreve a tradução, o evento GetPropertyChangedSignal dispara novamente — o processSet bloqueia esse loop.

Variáveis expostas

-- Acessíveis em outros scripts via getgenv():
genv.TranslatorLib  -- a classe (para criar novas instâncias)
genv.translator     -- instância ativa usada pelo loader

Atalhos de Teclado

F1Liga / Desliga a tradução. Ao religar, faz rescan completo da GUI.
F2Limpa cache e re-traduz tudo do zero. Útil ao entrar em nova área do jogo.
F3Estatísticas: breakdown de skip intencional / mesmo texto / falha de API / traduzidos / cache hits / uptime.
F4Log de erros — últimos 20 com horário, categoria (RUNTIME ERROR, API FAILED, SCAN ERROR, WATCH ERROR) e contexto.

Tentativa & Erro

Registro das abordagens testadas durante o desenvolvimento, o que funcionou, o que quebrou e por quê.

falhou
typeof(request) == "function" para detectar executor
A primeira tentativa de detectar funções de executor usava typeof(request) diretamente. Em executores como Xeno, acessar uma global inexistente sem proteção lança attempt to call a nil value. Typeof não é seguro para globals indefinidas em todos os ambientes.
resolvido
rawget(_G, "request") como alternativa segura
Substituir por rawget(_G, "request") retorna nil silenciosamente se a global não existir, sem lançar erro. Posteriormente foi descoberto que getgenv() é o padrão UNC correto, com fallback para _G.
falhou
loadstring(game:HttpGet(url))() em uma linha dentro de pcall
Quando o loadstring retorna nil (URL 404, HTML ao invés de Lua), o pcall captura o erro mas a mensagem era genérica e não distinguia se foi falha de download, compilação ou execução.
resolvido
Separar download → compilação → execução em etapas distintas
Separar em três pcalls independentes permite identificar exatamente onde falhou. Adicionado verificação de #raw > 0 antes de tentar compilar, evitando tentar parsear uma página HTML 404 como Lua.
falhou
HttpService:PostAsync como fallback para POST
LibreTranslate requeria POST com JSON. Tentamos usar HttpService:PostAsync() como fallback para executores sem request(). Além de adicionar dependência desnecessária de Studio API, instâncias públicas do LibreTranslate são instáveis e frequentemente offline.
resolvido
Remover LibreTranslate — Google + MyMemory são GET puro
Google Translate (endpoint gtx) e MyMemory aceitam GET com parâmetros na URL. Eliminar POST simplificou toda a camada HTTP. O projeto passou a depender apenas de game:HttpGet(), que está disponível em 100% dos executores testados.
falhou
name:find(word) para filtrar labels de dados do jogo
O filtro isSafeToTranslate usava name:find(word, 1, true) com substring match. UNSAFE_NAMES continha palavras curtas como "id", "name", "tag". Resultado: "DialogueLabel" era bloqueado por conter "id", "TitleName" por conter "name". A maioria dos labels de display legítimos era filtrada — causava 0 traduções.
resolvido
gmatch("[a-z]+") para segmentação por fronteira de palavra
Substituir por name:gmatch("[a-z]+") separa o nome em segmentos individuais de palavra. "DialogueLabel" vira {"dialogue", "label"} — nenhum bloqueado. "MutationValue" vira {"mutation", "value"} — ambos na lista. Adicionalmente, a lista UNSAFE_SEGMENTS foi reduzida a apenas campos que o jogo genuinamente lê de volta para lógica interna.
falhou
Modificar .Text causava crash em LobbyClient do jogo
Ao sobrescrever obj.Text com a tradução, scripts do próprio jogo que escutavam GetPropertyChangedSignal("Text") no mesmo label também disparavam. O LobbyClient lia o texto de volta esperando um valor específico (nome de mutation, stat) e lançava erros internos.
resolvido
Filtro pré-tradução por nome do objeto e conteúdo numérico
Implementado isSafeToTranslate(obj) que verifica o nome e o texto antes de qualquer processamento. Labels com segmentos de nome em UNSAFE_SEGMENTS ou com texto puramente numérico são ignorados completamente — nunca recebem watchObject e nunca têm .Text modificado.
falhou
pcall capturando só o booleano do IsA
local isText = pcall(function() return obj:IsA("TextLabel") end) — isText recebe o booleano de sucesso do pcall, não o resultado do IsA. O filtro de tipo nunca funcionava, qualquer objeto passava.
resolvido
local ok, isText = pcall(...) captura os dois retornos
pcall retorna success, ... onde ... são os valores retornados pela função. Separar em ok, isText captura corretamente: ok = sucesso da chamada, isText = resultado do IsA. Verificação com if not ok or not isText then return end.
falhou
WaitForChild bloqueando a thread principal
player:WaitForChild("PlayerGui", 10) na thread principal suspendia a execução por até 10 segundos se o PlayerGui ainda não tivesse carregado, travando o scan inteiro.
resolvido
FindFirstChild com fallback WaitForChild em task.spawn
FindFirstChild retorna imediatamente. Se nil, um task.spawn separado aguarda com WaitForChild de forma assíncrona, sem bloquear a thread principal.

Descobertas

Comportamentos encontrados durante o desenvolvimento que não eram óbvios de início.

descoberta
game:HttpGet() aceita URLs sem segundo argumento em executores
O segundo parâmetro booleano (game:HttpGet(url, true)) é documentado para Studio. Em executores, o parâmetro é ignorado ou causa comportamento inesperado em alguns deles. Removido — game:HttpGet(url) funciona uniformemente.
descoberta
Google Translate retorna JSON aninhado não padrão
O endpoint translate.googleapis.com/translate_a/single?client=gtx retorna um array aninhado em vez de JSON plano: [[["traduzido","original"...]...]]. Pattern %[%[%["(.-)" extrai o primeiro campo do primeiro array interno. Não há documentação oficial deste endpoint — foi descoberto por análise de resposta direta.
descoberta
getgenv() não existe em todos os executores
getgenv() é padrão UNC (Unified Naming Convention para APIs de executor), mas nem todos os executores implementam UNC completamente. Xeno, por exemplo, não tinha getgenv() disponível. Solução: (type(getgenv) == "function" and getgenv()) or _G.
descoberta
Typewriter effect dispara GetPropertyChangedSignal múltiplas vezes
Jogos como Deepwoken exibem texto caractere por caractere — cada caractere adicionado dispara o evento. Sem debounce, um diálogo de 50 caracteres geraria 50 requisições à API para o mesmo texto. O debounce de 0.8s aguarda a estabilização antes de traduzir.
descoberta
translate() descartava o reason silenciosamente
O método translate() foi escrito como local result = self:translateVerbose(...). Em Lua/Luau, ao atribuir múltiplos retornos a uma única variável, os valores extras são descartados sem erro. translate() retornava corretamente, mas o loader que chamava translate() nunca tinha acesso ao reason — forçou a migração para translateVerbose() em todas as chamadas do loader.
descoberta
string:match("^%s*(.-)%s*$") retorna nil em strings vazias
O padrão de trim s:match("^%s*(.-)%s*$") retorna nil quando a string é completamente vazia após sanitização (ex: texto que era só tags HTML). Concatenar nil com qualquer coisa lança erro. Fix: s:match(...) or "".

Troubleshooting

❌ Falha ao baixar / attempt to call a nil value

O executor não acessou a URL. Verifique: arquivo se chama exatamente Translate.lua no GitHub, URL começa com raw.githubusercontent.com, executor tem permissão HTTP.

⚠ Erro de compilação

A URL retornou HTML (página 404). Abra a URL no navegador — deve mostrar código Lua puro, não uma página web.

⚠ 0 textos traduzidos

O filtro isSafeToTranslate pode estar bloqueando labels legítimos. Ative DEBUG_SKIP = true para ver no console cada label pulado com o motivo. Use F4 para o log de erros.

⚠ Jogo quebrando após tradução

Um label que o jogo usa como dado está sendo traduzido. Pressione F4, identifique o nome do objeto no erro e adicione o segmento problemático em UNSAFE_SEGMENTS no loader.

⚠ Textos traduzidos pela metade

O typewriter effect é mais lento que o debounce. Aumente DEBOUNCE_TIME de 0.8 para 1.5 ou 2.0.
